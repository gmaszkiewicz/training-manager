## Notes

A management screen ("hub") reachable from the menu that opens when clicking the avatar.
It has a section menu like the one in settings; the first option is **Collaborations**.

1. **Trainer view**: a list of trainees assigned to the trainer, including those who have not yet accepted the link (status `pending`), with the ability to cancel a pending request, and the ability to unlink a trainee (the trainer loses access to their data).
2. **Trainee view**: a list of trainers the trainee is linked to, with accept / decline buttons (check / X) for incoming link requests.
3. **Drop auto-accept**: a trainer finding a trainee via search no longer links them automatically — instead a link request is sent and a toast is shown: "Your request has been sent to <email>" (Polish copy: "Twoja prośba została wysłana do <adres email>").
4. **Pagination on both lists**: pagination controls like on the measurements screen, with a per-page selector offering only the option 5.
