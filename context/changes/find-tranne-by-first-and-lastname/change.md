## Notes

Support searching for trainees in Find trainee by first name and last name as well.

1. Results are displayed the same way as in the Trainee column on Collaborations, with one difference: if a first name exists, it is shown in full.
2. Results in the trainee choice (Choose trainee) are presented the same way.
3. Component (tile) headings no longer name the specific trainee (e.g. `Weekly progression for A. Lovelace (ada@example.com)` becomes `Weekly progression`).
4. In Find trainee, the module checkboxes under Request for are laid out in two columns.
