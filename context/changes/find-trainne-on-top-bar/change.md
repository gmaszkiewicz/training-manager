## Notes

Move "Find trainee" into the top bar:

1) It sits at the top left as a search field with a magnifier icon and the label "Find trainee".
2) Clicking the search field opens a centered dialog, the same as the "Search documentation..." dialog on https://ui.shadcn.com/.
3) Esc or a click outside the dialog closes it.
4) On mobile the field stays if it fits; if it doesn't fit, show only the magnifier icon.
5) The centered dialog has the heading "Find trainee", below it "Request access to a trainee's dashboards", and a search field with the placeholder "Find trainee by email, first name or last name" (search by last name / first name will be added in a follow-up task).
   Below it, 4 checkboxes labelled "Request for": measurements, nutrition, training, planning — all disabled except measurements.
   At the end, a "Request access" button.
