## Notes

On the trainer profile page, a second option appears:

1. Change password as a button. The trainee profile has this button too.
2. Unlink trainees as a button. Only the trainer sees it.

Unlink trainees is new. After the trainer clicks it, a list of linked trainees appears, and each trainee can be unlinked. The page follows the home page style, with pagination and page sizes of 5, 10, and 15.

3. The profile in the header displays Trainee profile or Trainer profile.

S-32, MS-24. A trainer can unlink a linked trainee from a paginated list on Profile, both roles see Change password as a button, and the header profile reads Trainee profile or Trainer profile.
